## What's new in v0.3.5

**Startup banner:** airscope now prints a 3-line animated startup message before the TUI opens so the terminal never looks frozen during the 5-10 second startup.

**Splash screen completely redesigned:** clean 3-line text wordmark replaces the large ASCII logo art, adapter cards with capability badges, pulsing dot indicator, minimal professional layout.

**Scanner freeze mode:** press F to freeze the network list so it stops re-sorting while you choose a target - auto-freezes on arrow key navigation, amber banner shows frozen state, press F again to resume live sorting.

**Scanner redesigned:** BEACONS column removed, WPS folded inline into network name as a badge, preview strip shows selected network details below the table.

**Focus screen completely redesigned:** router and adapter ASCII art removed entirely, replaced with a clean target header card showing SSID/BSSID/channel/signal/encryption, 4-zone layout (header / attack cards / sparkline dashboard / log+clients).

**Attack buttons redesigned** as tall cards with always-visible plain-English descriptions.

**Animations and polish:** button hover effects, freeze banner transitions, pulsing dot on splash.
